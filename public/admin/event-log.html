1 Hub

Each V2 hub keeps its own "black box" in its EEPROM: warranty card, lifetime counters and the last ~476 events (faults, resets, updates, power cuts, node problems). It survives power cuts, updates and a flash erase. Nothing is sent by the hub on its own - this page asks for it. A full read takes about a minute over GSM. No network? Read it at the hub (BOOT button), see the Event Log guide.

2 Warranty card

No serial number on this hub yet. It can be set once from here (after that only at the hub's service console). Format: IRRIGO + year + series + unit, e.g. IRRIGO26AA10001.
